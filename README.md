# Project 01 — Case Study B: AI Job Market Intelligence

Responsive, bilingual portfolio extension in the visual style of the current six-card portfolio screenshot.

**Contains:** English/Spanish case study pages; JavaScript demonstration with fake job data and working filters; Python screening example; integration snippets.

**Does not contain:** personal CV data, recruiter lists, real applications, API keys, live job feeds, a deployed AI model or automatic emailing.

This package is intentionally **non-destructive**: it does not include or replace existing portfolio files.

## How to use

Read `INTEGRATE-PROJECT-01.md`, upload the files to the root of your public GitHub portfolio repository, and then paste its short integration links into your existing Project 01 English and Spanish pages.

Run sample locally with `python demo/scanner.py`.

All employers and results are fictional. Matching scores illustrate rule-based filtering; they do not predict employment outcomes.
