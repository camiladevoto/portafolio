Methodology & limitations

Roles with disqualifying seniority or domain requirements are excluded for a junior search. Remaining examples are scored using skill overlap, title relevance and optional published-contact preference. These scores are heuristic prioritisation signals, not probabilities of being hired.

Public data sources for a future live version include Greenhouse Job Board API and Lever Postings API. Public vacancy discovery, employer eligibility checking and recruiter email verification are still under development.

Portfolio project · Demonstration only · No user accounts, analytics or profile storage in this prototype.
