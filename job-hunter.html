Project 01 / Case Study B · Automation & AI

AI-Powered Job Market Intelligence

PythonAutomationData QualityProcess DesignPrivacy

Status: Public prototype. Not a live vacancy feed or a deployed AI model.

Designing a workflow to discover vacancies, screen eligibility, research published recruitment contacts, and reduce time wasted on unsuitable job listings.

Vacancy Screening, Data Quality, Automation, Privacy

Python prototype and live JobMatch tool.

The problem

01Less manual searching. Better decisions.

Fragmented sources

Openings are scattered across employer sites and job boards with inconsistent formats.

Misleading matches

Junior and remote labels can conceal disqualifying experience, language or geographic requirements.

Difficult outreach

Published contact details need checking before being used for an application.

Proposed workflow

02Five auditable stages

01Collect

Search permitted sources and record where each listing came from.

02Normalise

Standardise fields and remove duplicate postings.

03Check eligibility

Flag location, experience, language and specialist qualification constraints.

04Assess relevance

Compare requirements with documented skills and show uncertainty.

05Verify contacts

Separate actual application emails from general contacts and save the source.

Real-life application

03JobMatch

I built JobMatch to apply the job-screening idea to real vacancies. It lets you filter listings by location and remote work options, including roles you can do from Spain.

Privacy and limitations

05Public demonstration, private data

This public repository uses fictional data only. Real CVs, recruiter contacts, application history and access keys belong in a separate private repository. Scores are simple heuristics, not predictions of hiring outcomes. No emails are sent automatically.

06Next steps

Integrate permitted public vacancy feeds, measure screening quality against manual review, and add source-backed contact verification. Features will be marked implemented only after testing.
